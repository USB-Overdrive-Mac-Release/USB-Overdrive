## Frequently Asked Questions

**What hardware does it handle?**
Any USB or Bluetooth mouse, keyboard, trackball, joystick, gamepad or gaming device, from any manufacturer.
The breadth is the point: the driver is written against the devices themselves rather than against a
particular vendor's product line.

**Does the brand of my device matter?**
It does not. Hardware from any manufacturer is handled through the same interface, which is what makes usb
overdrive mac useful on a desk assembled from whatever was good at the time rather than from one catalogue.

**Which controls can it see?**
All kinds of wheels, buttons, keys, switches and controls. If the device reports a control, the driver can
generally read it and hand it to you for assignment — including the ones the system otherwise ignores.

**What can I make those controls do?**
They can be assigned to useful actions such as clicking, typing, scrolling, launching applications and
opening documents. That range is what turns an unused side button into a genuine shortcut rather than a
second-rate duplicate of the left click.

**Can settings differ from application to application?**
Yes. A device can be configured either globally or for specific applications, so the same control behaves
one way in general and another way inside a particular program. Per-app scope is the feature most people
mean when they go looking for a button mapping mac utility.

**How many devices can it manage at once?**
Several USB devices can be handled simultaneously, and different settings can be assigned to each one. A
mouse, a trackball and a gamepad can share a desk without sharing a configuration.

**Is Bluetooth really covered, or only USB?**
Bluetooth devices are covered as well. A wireless mouse or keyboard is set up exactly like a wired one, so
the name of the application is narrower than what it actually handles.

**Do I still need the software that came with my device?**
Generally not — replacing a collection of per-brand utilities with a single usb device driver mac
installation is the reason the driver exists. One configuration interface, whatever the hardware.

**Will it help with a gaming controller?**
Joysticks, gamepads and gaming devices are explicitly supported, so their controls can be mapped to actions
on the Mac through the same driver that handles your pointer.

**Is it worth it for a plain two-button mouse?**
Honestly, less so. The value scales with how many controls your hardware has and how much you want them
scoped per application. If nothing on your desk has an unused button, download usb overdrive for mac is not
solving a problem you have.

**What does it cost?**
It is a $20 system utility, currently at version 5.1, in the System Utilities category.

## About

USB Overdrive exists because input hardware and operating systems have never quite agreed on how much of a
device should be usable. Manufacturers ship controls; the system exposes the common ones; the remainder
depends on whichever utility the vendor felt like maintaining, for as long as they felt like maintaining it.
A universal driver sidesteps that arrangement entirely — it reads the device directly and puts the mapping
decision with the person using it. That is why a usb overdrive mac download often outlasts several
generations of peripherals, and why usb overdrive for mac tends to be the first thing reinstalled on a new
machine by anyone who has grown used to their buttons doing what they were told.
